How this pack was made. Nothing here is a “memory-based” paper. Each question and each answer was read from the PDFs hosted on the Commission's own website, and the transcriptions were cross-checked against the official answer key (a mismatch would have shown up as a wrong answer on 99 objectively verifiable questions). The scan/OCR layer of the official PDF is imperfect, so the English text has been cleaned up — wording, options and numbering are unchanged.

How to use the 2023 paper

  1. Sit the paper in one 90-minute block, OMR-style: 1 mark each, −0.25 for a wrong answer, no penalty for a blank.
  2. Score with the Series-A grid in the answer-key file. Anything above the General cut-off (49) is a pass, but aim for 70+ so that Part-II carries less pressure.
  3. Tag every mistake by topic — English grammar/vocabulary, static GS, current affairs, arithmetic — and note that after Q.30 the General Studies and Arithmetic questions are interleaved, so you cannot “switch off” between sections.
